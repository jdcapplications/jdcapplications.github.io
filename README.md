JDC Applications — website

Static site served by GitHub Pages.
Repo MUST be named: jdcapplications.github.io

Structure
  index.html              Company landing  -> jdcapplications.com
  bottlewise/index.html   BottleWise page  -> jdcapplications.com/bottlewise
  bottlewise/privacy.html -> /bottlewise/privacy.html
  bottlewise/support.html -> /bottlewise/support.html
  CNAME                   Custom domain (jdcapplications.com)
  .nojekyll               Serve files as-is

Adding another app later: create a new folder (e.g. /nextapp/index.html).
It will be served at jdcapplications.com/nextapp automatically.
